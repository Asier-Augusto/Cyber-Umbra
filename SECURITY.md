# Responsible use

Cyber Umbra is for **authorized, scoped** web security assessment only.

- Do not use any concept or material from this repository to access, test, or interfere
  with any system without the owner's explicit written authorization. Doing so may be
  illegal.
- This public repository is a **beta preview** and contains **no exploit code** and no
  runnable offensive capability.
- It is not accepting vulnerability reports or external contributions at this stage.
